# Birdie & Claire 🦜

Birdie and Claire's Outfit Styling Hub enables shoppers to see the value of Birdie and Claire items. By allowing users to create outfits recommended for them, creating outfits by occasion, and providing ways for users to interact with clothing items, we encourage connections to shoppers for brands to increase item-to-purchase conversion.
